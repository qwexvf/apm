`ccpm.lock` records the exact resolved version, commit SHA, and install path for every plugin. It is generated by ccpm and should be committed to git.

## File location

Same directory as `ccpm.toml` — `~/.claude/ccpm.lock` (user scope) or `.claude/ccpm.lock` (local scope).

## Format

```toml
[[plugin]]
id           = "figma@claude-plugins-official"
version      = "2.1.30"
commit_sha   = "3590366424deba5651026319b71b291d10004f1b"
resolved_url = "https://github.com/anthropics/claude-plugins-official"
install_path = "/home/user/.claude/plugins/cache/claude-plugins-official/figma/2.1.30"
integrity    = "sha256:a1b2c3d4..."

[[plugin]]
id           = "caveman@caveman"
version      = "ef6050c5e184"
commit_sha   = "ef6050c5e1848b6880ff47c32ade1a608a64f85e"
resolved_url = "https://github.com/JuliusBrussee/caveman"
install_path = "/home/user/.claude/plugins/cache/caveman/caveman/ef6050c5e184"
integrity    = "sha256:b2c3d4e5..."
```

## Fields

| Field | Description |
|-------|-------------|
| `id` | Plugin identity: `name@marketplace` |
| `version` | Resolved version — semver tag (e.g. `2.1.30`) or short SHA (e.g. `ef6050c5e184`) |
| `commit_sha` | Full 40-character git commit SHA |
| `resolved_url` | GitHub repo URL used as the source |
| `install_path` | Absolute path where the plugin files are extracted |
| `integrity` | SHA256 hash of the downloaded tarball for verification |

## Rules

- **Never edit `ccpm.lock` by hand.** It is generated by `ccpm add`, `ccpm update`, and `ccpm lock`.
- **Always commit `ccpm.lock`** alongside `ccpm.toml`. Together they guarantee reproducible installs.
- `ccpm install` reads the lockfile and installs exact versions — it never modifies the lockfile.
- `ccpm update` is the only command that updates existing locked versions.

## Regenerating

If the lockfile gets out of sync with the manifest:

```sh
ccpm lock   # re-resolve all constraints and write fresh ccpm.lock
```
