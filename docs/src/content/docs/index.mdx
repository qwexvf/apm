**apm** is a plugin manager for [Claude Code](https://claude.ai/code) that brings `npm ci`-style reproducible installs to Claude Code plugins.

Claude Code's built-in plugin system has no lockfile, no version constraints, and no guaranteed reproducibility — reinstalling on a new machine may pull a different version than what your team tested with. apm fixes that.

## What apm adds

- **Declarative manifest** (`apm.toml`) — list plugins + version constraints
- **Lockfile** (`apm.lock`) — exact versions + commit SHAs, committable to git
- **Reproducible installs** — `apm install` from a lockfile always gets the same code
- **Semver constraints** — `^2.1.0`, `~1.0`, `*`, exact tags, commit SHAs, branches
- **Marketplace management** — register custom marketplaces beyond the official one
- **State repair** — `apm sync` fixes Claude Code's registry without re-downloading

## Quick example

```sh
apm init
apm add figma@claude-plugins-official@^2.1.0
apm add caveman@caveman
```

Produces `apm.toml`:

```toml
[plugin_manager]
scope = "user"

[plugins]
"figma@claude-plugins-official" = "^2.1.0"
"caveman@caveman" = "*"
```

And `apm.lock` with exact versions pinned. Commit both files. On a new machine:

```sh
apm install   # installs exact versions from lockfile
```
