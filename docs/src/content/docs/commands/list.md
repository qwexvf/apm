Show all plugins in the manifest with their installed version and status.

## Usage

```sh
apm list
```

## Example output

```
PLUGIN                               VERSION     CONSTRAINT  STATUS
figma@claude-plugins-official        2.1.30      ^2.1.0      installed
caveman@caveman                      ef6050c5    *           installed
gopls-lsp@claude-plugins-official    1.0.0       1.0.0       installed
```
